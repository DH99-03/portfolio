Project 01

LS ROKETS

LS JUMP-UP · 2026.09 · 3인 팀

설비 경보를 '무엇부터 확인할지'로 바꾸는 예지보전 점검 대시보드

문제

경보가 여러 개 뜨면 담당자는 무엇부터 봐야 할지 판단하기 어렵고, 온도·회전속도·토크·공구 사용시간을 숫자로만 보면 복합 조건을 해석하기 힘듭니다.

접근

  • 점검 대상 선정 → 상세 진단 → 조건 조정 검토 → 기록으로 이어지는 현장 점검 / 사무실 관제 화면 흐름 설계
  • AI4I 2020 데이터에 물리 관계 피처 3개(온도차·기계적 출력·공구 부하) 추가, 학습·보정·시험 구간을 분리해 유형별 모델과 임계값 선정
  • MySQL + SQLAlchemy로 사용자별 검토 이력과 감사 기록, Argon2id·AES-256-GCM 보안

내 역할

  • 현장·사무실 업무 흐름 기획과 화면 통합 요구사항 정의
  • Codex로 구현한 화면을 직접 검수하며 기록 선택·상세 이동·그래프 갱신 개선 요청
  • 모델 결과와 표시 기준 검토, 팀 접속·진행 공유 조율

Project 02

Spot!

LG DX SCHOOL 최종 프로젝트 · 2024.10 – 12 · 팀장 · 6명 → 4명

모델명을 몰라도 사진 한 장으로 가전을 인식하고, 그 제품에 맞춰 답하는 AI 챗봇 앱

지능형 고객경험데이터 분석 서비스 프로젝트 우수상

문제

커뮤니티·영상 크롤링과 설문 66명을 분석해 보니, 사용자는 설명서를 끝까지 읽지 않고 모델명을 모르면 검색 단계부터 막혔습니다.

접근

  • LG 냉장고 4종 이미지 2,088장으로 YOLO11x 전이학습 → 사진으로 제품 인식
  • 한국어 Llama3 8B를 매뉴얼·오류코드·Q&A로 LoRA 미세조정, ChromaDB RAG로 인식된 제품 범위 안에서만 답변
  • Flutter 앱 ↔ FastAPI ↔ MySQL, WebSocket 실시간 답변

내 역할

  • 팀장 — 팀원이 6명에서 4명으로 줄었을 때 WBS를 다시 나누고 일정 조율, 최종 발표
  • LLM 파인튜닝 전담
  • DB 설계와 연동, 모델과 백엔드를 Docker 이미지로 띄워 AWS에 배포
  • 웹 UI/UX 공동 작업
